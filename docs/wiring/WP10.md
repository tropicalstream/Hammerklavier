# WP10 wiring (wp10-ui)

## Swap
- `Wiring.ui`: `StubUi()` → `com.tropicalstream.hammerklavier.ui.model.UiStateMachineImpl()`
- `Wiring.overlay(ctx)`: `StubOverlay(ctx)` → `com.tropicalstream.hammerklavier.ui.OverlayViews(ctx)`

## Hook-ups (main thread)
- After every `ui.render(facts, now)` → `overlay.show(state)`; also on a 1 Hz tick while the stage shows
  (the views only invalidate what changed).
- `(state as UiOverlayState).stageHidden` → `render.setStageHidden(..)` when it changes (Display floor card).
- `ui.onEvent(...)`: KIT_PLAYABLE (KitCallback), ENTERED, MOVEMENT_STARTED, VIEW_CHANGED, PAUSED/RESUMED,
  REST_ON/REST_OFF (Q3), IMPORTED.
- `ui.creditsText = assets/credits.txt` (read once on HKLoader, set on main).
- CONTROL: `--ez menu true` → `ui.openTransport()`; `--ez library true` → apply `ui.openLibrary()`;
  `--es card floor|sync` → apply `ui.openCard(CardKind.FLOOR|SYNC, facts)`; then re-render.
- `--es gesture ...` → `ui.onGesture(...)` exactly as the pad (SYSTEM_BACK = `sysback`).
- Settings: none written by WP10 (all through UiActions).
