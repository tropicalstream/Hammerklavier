# WP10 requests

1. **WP0 (contract):** `UiAction.SetSight(edgeOverlay = null)` means "unchanged", so More › Sight ›
   Edge overlay › **Auto** cannot be expressed. Proposal (growth rule: appended, defaulted):
   `autoEdgeOverlay: Boolean = false` on `SetSight`. Until then the Auto row shows but emits nothing.
2. **WP0 (wiring):** `RenderControl.setStageHidden` has no UiAction. WP10 exposes it as
   `UiOverlayState.stageHidden` (true while the Display floor card shows); AppController should call
   `render.setStageHidden(state.stageHidden)` when it changes after `ui.render(...)`.
3. **WP12 / WP9 / WP4 (StatusItem args):** the argument conventions WP10's UiText reads are listed
   in the KDoc of `ui/model/UiText.kt` (e.g. IMPORT_FAILED = [name, RejectReason.name, detail?],
   FALLBACK = [FallbackReason.name], IMPORTED = [name, notes, durationSec]). Please emit these.
4. **WP12 (shelf ids):** `UiAction.Play.shelfId` is the catalogue shelf id, or the virtual ids
   `MenuTree.SHELF_START = "start-here"` and `MenuTree.SHELF_RECENT = "recent"`. The Imported shelf
   is expected under id `"imported"` (shown with its count only when not empty).
5. **WP0 / WP12 (A/V lead):** the A/V sync card needs the effective lead for the current route, including the
   measured Bluetooth default of §8.6 when no key is stored. Proposal (appended, defaulted): `UiFacts.effectiveLeadMs: Int?`.
   Until then the card starts from `settings.avLeadMs[route.key] ?: 30`. The card no longer previews live
   (SetAvLead stores), so a non-storing `UiAction.SyncPreview(ms)` would be welcome to restore the live preview.
6. **WP12 (sessions):** WP10 shows the hint when `firstRun` is true or `sessions in 1..3`; please make
   `sessions` 1-based, counting the current session.
